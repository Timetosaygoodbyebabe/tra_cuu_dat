# HUONG DAN CHAY BACKEND BANG PM2 (DANH CHO IT/DEVOPS)

De dam bao Backend NodeJS luon chay ngam va tu dong khoi dong lai khi server bi cup dien/restart, vui long su dung PM2 theo cac buoc sau:

Buoc 1: Cai dat PM2 (neu may chu chua co)
npm install -g pm2

Buoc 2: Di chuyen vao thu muc chua code backend
cd "C:\Users\IOC\Desktop\Kiem com\tra_cuu_dat\backend"
(Hoac duong dan tuong ung noi luu tru code tren server)

Buoc 3: Khoi chay Backend bang PM2
pm2 start npm --name "zalo-backend" -- run dev

Buoc 4: Luu danh sach tien trinh hien tai de khoi phuc khi restart
pm2 save

Buoc 5: Cau hinh tu dong bat PM2 khi khoi dong may
pm2 startup
(Sau khi chay lenh nay, neu he thong yeu cau copy paste them lenh gi do thi copy chay tiep)

# CAC LENH QUAN LY TIEN TRINH (KHI CAN):
- Xem danh sach cac tien trinh dang chay:
pm2 list

- Xem log de kiem tra tien trinh (xem backend co tai data duoc khong):
pm2 log zalo-backend

- Khoi dong lai backend (sau khi ban cap nhat code moi):
pm2 restart zalo-backend

- Dung (tat) backend:
pm2 stop zalo-backend
